# Planned features

The recommendation set in `docs/feature-recommendations.md` now has a baseline implementation across P0, P1, and P2:

- diagnosis and learner goals;
- competency matrix and evidence;
- remediation actions and reassessment;
- actionable mentorship follow-up;
- mentor attention ownership and SLA;
- deterministic adaptive learning recommendations;
- GitHub exercise checks;
- versioned, editorially reviewed templates;
- verifiable portfolio evidence;
- cohort projects, moderated peer review, and derived peer-review reputation.

## Deliberately deferred

These are not required for the current baseline and should not be added without a new product decision:

- automatic peer-review matching;
- paid or mentorship projects enrolled through a cohort;
- reputation as a competency score or merge permission;
- generic social feeds, chat, event buses, repositories, or code-execution infrastructure;
- automatic approval of code or competency by AI.
