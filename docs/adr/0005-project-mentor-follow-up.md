# Acompanhamento separado para Mentores de projeto

O produto terá um espaço próprio de **Acompanhamento** em Work para pessoas com vínculo ativo de Mentor de projeto, sem substituir o dashboard do aluno e sem reutilizar o Dashboard administrativo ou a fila global `mentorAttention`. O Acompanhamento será limitado aos projetos sob responsabilidade do mentor, agrupará cada mentorando uma única vez e combinará resumo operacional com pendências objetivas — revisões de Pull Request ativas e pendentes e tarefas ou Sprints atrasadas — levando sempre ao fluxo original, sem status paralelo, dispensa ou notificações. Revisões de exercício ficam fora até que tenham vínculo explícito com projeto; sessões próximas aparecem como contexto. Essa separação preserva a fronteira entre Mentor e Admin e evita inferir autorização ou proveniência de dados que os modelos atuais não representam.
